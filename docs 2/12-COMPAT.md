# 12 — Совместимость с другими модами

Требование заказчика: совместимость с другими модами, энергией, ресурсами типа
олово/медь.

**Принцип:** мод должен быть **хорошим соседом**. Мы не навязываем свои руды, не
дублируем чужие системы, не лезем миксинами в чужой код. Вся совместимость — через
теги, публичные API и отменяемые события.

---

## 1. Три уровня совместимости

| Уровень | Что это | Требует ли чужой мод |
|---------|---------|---------------------|
| **Базовый** | Теги материалов, Forge Energy, жидкости, инвентари | Нет. Работает всегда |
| **Мягкий** | Опциональные интеграции, включаются если мод найден | Нет, но улучшает |
| **Модуль** | Отдельный compat source set под конкретный мод | Да |

---

## 2. Базовый уровень (работает всегда)

### Энергия

Только **Forge Energy** (`IEnergyStorage`). Своей энергосистемы нет.
Принимаем энергию от любого мода: Mekanism, Thermal, Immersive Engineering,
Create (через Create: Crafts & Additions), Powah, Flux Networks и т.д.

Генерации энергии мод **не добавляет** — осознанно. Исключение: один
примитивный **биогенератор** на биомассе для самого старта, когда у игрока ещё
нет техномода. Слабый, чтобы не конкурировать.

### Материалы — только по тегам

```
c:ingots/copper      c:ingots/tin        c:ingots/lead
c:ingots/steel       c:ingots/aluminum   c:ingots/silver
c:plates/*           c:dusts/*           c:gears/*      c:rods/*
c:rubber             c:silicon           c:glass_panes
```

**Своих руд не добавляем вообще.** Это:
- не трогает генерацию мира,
- не конфликтует с техномодами,
- не требует от игрока ещё одного цикла добычи.

Свои ресурсы — только биологические расходники (биомасса, среда, ферменты,
картриджи), которые никто больше не делает.

### Fallback-рецепты

Если техномодов нет, часть рецептов требовала бы недоступных материалов.
Решение: **условные рецепты** (`neoforge:conditions` в датапаке) — при
отсутствии тега работает упрощённый рецепт из ванильных ресурсов.

```json
{
  "neoforge:conditions": [
    { "type": "neoforge:tag_empty", "tag": "c:ingots/tin" }
  ],
  "type": "minecraft:crafting_shaped",
  "...": "вариант рецепта на железе вместо олова"
}
```

### Жидкости и предметы

- `IFluidHandler` для всех машин с жидкостями
- Свои жидкости: питательная среда, растворитель, загрязнённая вода, дезинфектант
- `IItemHandler` для всех инвентарей
- Поддержка автоматизации любыми транспортными модами «из коробки»

### Мобы чужих модов

Работают **автоматически**, если попадают в теги хостов. Для популярных
мод-паков добавим готовые теги в датапак. Моддер добавляет своих мобов одной
строкой тега — см. [11-ADDON-API.md](11-ADDON-API.md).

Тег `biohazard:immune` позволяет исключить мобов (боссы, питомцы, квестовые NPC).

## 3. Мягкий уровень (включается, если мод найден)

### Клейм-моды — обязательно

**FTB Chunks, Open Parties and Claims, GriefPrevention, FTB Teams.**

Если установлены — порча блоков и утечка загрязнения **не действуют в чужих
клеймах**. Реализуется через наш собственный отменяемый
`BlockCorruptionEvent` + тонкий адаптер на API клейм-мода. Если API нет —
fallback на общий конфиг-радиус защиты.

Это критично даже для кооп-сервера на 5 человек.

### JEI / EMI / REI

- Все рецепты машин видны
- **Отдельные категории** для лабораторных процедур
- Информационные страницы: гены (только открытые игроком!), профили хостов,
  клеточные линии
- Кнопка перехода в Кодекс
- ⚠️ JEI не должен раскрывать неизвестные игроку гены — нужен фильтр по знанию

### The One Probe / Jade / WAILA

Показ при наведении: состояние машины, прогресс процедуры, герметичность
помещения, уровень загрязнения чанка, состояние заражения моба (**только то, что
игрок может видеть глазами или приборами**).

### Patchouli

**[решение автора]** Кодекс делаем **своим**, а не на Patchouli: нужны
динамические страницы (дерево родословной, открытые правила, графики), которые
Patchouli не умеет. Но при наличии Patchouli добавим тонкую книгу-«введение» со
ссылкой в Кодекс.

### Моды динамического освещения

Биолюминесцентные заражённые дают реальный свет, если установлен мод
динамического освещения. Свой динамический свет не делаем (см.
[10-ARCHITECTURE.md](10-ARCHITECTURE.md), раздел 8).

### Sodium / Embeddium / Iris

Постэффекты с мягкой деградацией: если шейдерные эффекты недоступны — работают
упрощённые версии через оверлеи. Никаких падений.

### Моды сна/жажды/еды (Serene Seasons, Thirst, Diet, Farmer's Delight)

- Загрязнение еды работает с едой любых модов
- `symptom/insomnia` корректно взаимодействует с чужими механиками сна
- Жажда: загрязнённая вода даёт дозу

## 4. Модули под конкретные моды

### Create (явно запрошен заказчиком)

Create — лучший тематический партнёр: его механизмы визуально идеально
подходят лаборатории.

| Интеграция | Что даёт |
|------------|----------|
| **Кинетический привод для машин** | Центрифуга, смеситель, перемешиватель биореактора могут работать **на вращении вместо FE**. Выбор игрока: механика или электричество |
| Рецепты в Mixing/Compacting | Питательная среда, реагенты, биомасса — через механизмы Create |
| Жидкости и трубы Create | Полная совместимость для среды и реагентов |
| Create: контрапции и поезда | Герметичные контейнеры корректно работают на подвижных конструкциях |
| **Вентиляторы Create** | Могут играть роль вентиляции в пассажной камере (отбор на аэрозольную передачу) — очень приятная синергия |
| Ponder | Наши многоблоки получают сцены Ponder, если Create установлен |

Кинетический привод — хорошая идея: даёт раннюю альтернативу энергии и делает
лабораторию визуально живой.

### Mekanism / Thermal (явно запрошены)

| Интеграция | Что даёт |
|------------|----------|
| **Газы Mekanism** | Кислород для биореактора, азот для криохранилища, хлор/водород как дезинфектанты |
| **Химические цепочки** | Реагенты можно получать через химию Mekanism вместо своих рецептов |
| **MekaSuit** | Заявляет свою защиту через `IProtectiveEquipment`. Модуль био-фильтрации как апгрейд MekaSuit |
| **Радиация Mekanism** | Синергия: радиация повышает частоту мутаций (`hostMutagenFactor`). Мутагенная камера может работать на радиоактивных отходах Mekanism — отличная утилизация |
| Thermal: машины и жидкости | Взаимная совместимость рецептов |
| Ядерные отходы | Использование как мутагена — осмысленная переработка |

Связь радиации с мутациями — лучшая находка в этом списке: она биологически
верна и соединяет два мода геймплейно, а не косметически.

### Immersive Engineering

Вентиляция, трубы, бетон, индустриальная эстетика. Наши герметичные панели
должны стыковаться визуально. Возможность использовать их бетон как материал
оболочки (через тег `biohazard:sealing/*`).

### Applied Energistics 2 / Refined Storage

- Образцы, картриджи, праймеры — нормально хранятся в сетях
- **Генный банк** как часть системы хранения
- ⚠️ Проверить: предметы с `DataComponent` не должны схлопываться в сети в один
  стак (разные штаммы = разные предметы). Это классический баг совместимости

### Farmer's Delight / сельхоз-моды

Растительные вирусы работают с их культурами через теги. Полезные штаммы
(урожайность) — заметная выгода.

### Alex's Mobs / Ice and Fire / мобовые моды

Их мобы попадают в хосты по тегам. Для популярных — готовые теги в датапаке.
Боссы — в `biohazard:immune`.

### KubeJS / CraftTweaker

Отдельный модуль, см. [11-ADDON-API.md](11-ADDON-API.md), раздел 4.

## 5. Чего мы НЕ делаем

| Чего не делаем | Почему |
|----------------|--------|
| Миксины в чужой код | Хрупко, конфликтует, ломается при обновлениях. Только публичные API |
| Своя энергосистема | Дублирование. Принимаем FE |
| Свои руды | Конфликт с техномодами, лишняя генерация |
| Своё измерение | Не нужно концепции |
| Жёсткая зависимость от любого мода | Мод должен работать соло |
| Замена ванильных механик | Мы добавляем, а не переделываем |
| Перерегистрация чужих сущностей/блоков | Только теги и события |

## 6. Матрица тестирования совместимости

Проверять перед каждым релизом. Минимальный набор:

| Сборка | Что проверяем |
|--------|---------------|
| Только Project Biohazard | Мод полностью проходим соло, fallback-рецепты работают |
| + Create | Кинетический привод, рецепты, вентиляторы |
| + Mekanism | Энергия, газы, MekaSuit, радиация-мутаген |
| + Thermal + Immersive Engineering | Энергия, материалы по тегам |
| + AE2 | Предметы с компонентами не схлопываются |
| + FTB Chunks | Порча не заходит в чужой клейм |
| + JEI | Рецепты видны, скрытые гены не раскрыты |
| + Jade/TOP | Нет утечки скрытой информации |
| + Sodium/Embeddium/Iris | Клиент не падает, эффекты деградируют мягко |
| + Alex's Mobs | Мобы болеют, рендер-слой не падает |
| Крупный сборный модпак (100+ модов) | Нет конфликтов регистрации, TPS держится |

## 7. Что сделать, чтобы мод любили авторы модпаков

- **Всё настраиваемо датапаком** — автор модпака может перебалансировать всё, не
  трогая код
- **Готовые профили сложности** как датапаки
- **Теги для всего** — любая интеграция возможна без нас
- **Отменяемые события** — серверные плагины могут вмешаться
- **Нет обязательных зависимостей**
- **Честный лог**: при старте пишем, какие интеграции активировались
- **Команды админа** для разбора ситуаций на сервере
- **Документация API** и пример-аддон в репозитории
