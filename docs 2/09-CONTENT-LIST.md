# 09 — Полный список контента

Список целевой. Для первой версии см. [15-ROADMAP.md](15-ROADMAP.md) — там
выделено минимально необходимое.

Обозначения: 🔋 потребляет энергию (FE) · 🧫 работает с патогеном (требует BSL) ·
🏗 многоблок · ⚙ принимает карту протокола (автоматизируемо)

## 1. Машины и блоки лаборатории

### T0 — Полевая биология (без энергии)

| Блок | Роль |
|------|------|
| **Полевой микроскоп** | Шасси штамма, длина цепи, признаки патогена в образце |
| **Полевой верстак биолога** | Крафт базовых расходников, набор для образцов |
| **Стойка для образцов** | Хранение образцов с отображением состояния |

### T1 — Культивирование

| Блок | Роль |
|------|------|
| 🔋🧫⚙ **Инкубатор** | Выращивает вирус на клеточной культуре или в яйце. Параметры: температура, время, MOI |
| 🔋 **Банк клеточных культур** | Получение и поддержание клеточных линий по видам. Расходует питательную среду. **Без подачи среды линии гибнут** |
| 🔋🧫 **Биобокс (ламинарный шкаф)** | Локальное сдерживание + защита культуры от контаминации |
| 🔋 **Автоклав** | Стерилизация предметов, обработка биоотходов |
| 🔋🧫 **Бляшечный анализатор** | Измерение титра образца |
| 🔋 **Центрифуга** | Очистка, концентрирование, разделение фракций |
| 🔋 **Переработчик биомассы** | Органика → биомасса |
| 🔋⚙ **Смеситель среды** | Биомасса + вода + сахар → питательная среда |
| 🔋🧫 **Инактиватор** | Нагрев/химия → инактивированная вакцина |
| **Контроллер сдерживания** | Мозг помещения: герметичность, диагностика, журнал инцидентов, тревога |
| **Герметичная панель / бетонная панель / лабораторное стекло** | Оболочка помещения, разные `sealQuality` |
| **Герметичная дверь** | Закрытая = герметичность |
| 🔋 **Криохранилище** | Банк образцов: мутации остановлены, титр не падает |
| **Утилизатор биоотходов** | Уничтожение загрязнённых отходов |
| 🔋 **Исследовательский терминал** | Дерево исследований, трата очков |

| 🔋 **Дезактивационный душ** | Обязателен при выходе из BSL-3+ |
| 🔋 **Аварийная сигнализация** | Звук и свет при падении герметичности |
| 🔋 **УФ-излучатель** | Деконтаминация по прямой видимости |
| 🔋 **Генератор дезинфекционного тумана** | Деконтаминация помещения/чанка |
| 🔋 **Холодильник** | Предметы не набирают загрязнение, титр падает медленнее |

## 2. Предметы

### Сбор и анализ

| Предмет | Роль |
|---------|------|
| **Набор для образцов** | Взятие образцов: мазок, кровь, ткань, вода, почва, растение |
| **Пробирка с образцом** | Несёт: штамм (возможно неизвестный), титр, тип материала, время взятия |
| **Чашка Петри / флакон культуры** | Носитель растущей культуры |
| **Клеточная линия** (предмет) | Привязана к виду/профилю хоста |
| **Термобокс** | Переносное охлаждение: образцы не деградируют в походе |
| **Полевой тестер загрязнения** | Уровень загрязнения в чанке |
| **Дозиметр** | Накопленная доза игрока + тикающий звук. Ключевой предмет ощущения |
| **Шприц для забора крови** | Диагностика: заражён ли хост, какой штамм |
| **Карта протокола** | Найденный рабочий режим процедуры. Переиспользуется, автоматизируется, передаётся |
| **Праймер** | Привязан к гену. Открывает амплификацию |
| **Исследовательские записи** | Лут: очки исследований или сразу открытое правило |

### Генетика

| Предмет | Роль |
|---------|------|
| **Генный картридж** | Извлечённый ген. Торгуемый, коллекционируемый объект |
| **Спейсерная вставка** | Нейтральная вставка для разнесения конфликтов |
| **Плазмидный остов** | Расходник для клонирования |
| **Плазмидная конструкция** | Остов + ген, готов к переносу |
| **Нуклеотидный субстрат** | T3+: сырьё для синтеза генов |
| **Чертёж генома** | Спроектированная раскладка. Не живой вирус — проект |

### Медицина

| Предмет | Роль |
|---------|------|
| **Вакцина** (4 типа) | Инактивированная, живая ослабленная, субъединичная, универсальная. Несёт целевую подпись/ген |
| **Шприц** | Применение вакцины/препарата на себе или на хосте |
| **Вакцинный дротик** | Применение на расстоянии (духовая трубка/арбалет) |
| **Антивирус** (4 типа) | Широкого спектра и целевые |
| **Антисыворотка** | Экстренное средство. Живёт 2 игровых дня |
| **Моноклональные антитела** | Точно против одного штамма |
| **Индуктор** | Топливо для `reg/kill_switch`. **Постоянный расход на весь симбионтный билд** |
| **Стабилизирующий реагент** | Повышает стабильность генома |
| **Аптечка полевая** | Поддерживающая терапия вне базы |

### Расходники

Питательная среда · селективная среда (антибиотик) · ферменты · рестриктазы ·
фильтрующий картридж · баллон воздуха · криоагент · дезинфицирующий реагент ·
биомасса · загрязнённые биоотходы · использованный фильтр

| Комплект | Тир | Слоты | Особенности |

## 5. Сущности

| Сущность | Роль |
|----------|------|
| **Заражённые варианты ванильных мобов** | Не новые сущности, а аттачмент + рендер-слой + AI-цели. **Это важно: не плодим мобов** |
| **Подопытное животное** (в камере) | Условная сущность внутри многоблоков, упрощённая |
| **Вакцинный дротик** | Снаряд |
| **Облако аэрозоля** | Короткоживущая сущность от распылителя/аварии |
| **Споровое облако** | От `spore_vent` |
| **Медицинский дрон** (T3, опционально) | Летает по базе, вакцинирует/лечит |

**Принципиально: никаких «заражённых зомби-мутантов» как отдельных мобов.**
Заражение — это состояние существующего моба. Так мод остаётся совместимым с
любыми мобами из других модов и не раздувает регистр сущностей.

## 7. Теги (ключ к совместимости)

### Свои теги, на которые должны реагировать другие моды

```
biohazard:host/mammal          biohazard:host/avian
biohazard:host/aquatic         biohazard:host/arthropod
biohazard:host/undead          biohazard:host/primate
biohazard:host/plant           biohazard:host/fungal
biohazard:host/nether_fauna
biohazard:immune               — полностью исключить сущность из системы

biohazard:sealing/perfect      biohazard:sealing/good
biohazard:sealing/poor         — качество оболочки помещения
biohazard:corruption_immune    — блок не портится
biohazard:sealed_armor         — броня даёт базовую защиту
biohazard:sealed_container     — контейнер защищает содержимое
biohazard:sterilizable         — предмет можно автоклавировать
biohazard:tissue_source        — с предмета можно получить клеточную линию
biohazard:nutrient             — годится как питательная среда
```

### Чужие теги, которые используем

```
c:ingots/copper, c:ingots/tin, c:ingots/lead, c:ingots/steel, c:ingots/aluminum
c:plates/*, c:dusts/*, c:gears/*, c:rods/*
c:rubber, c:silicon, c:glass_panes
forge:/c: теги энергии и жидкостей
```

Своих руд **не добавляем**. При отсутствии техномодов работают fallback-рецепты
из ванильных ресурсов через условия датапака.

## 8. Чего намеренно НЕТ

| Чего нет | Почему |
|----------|--------|
| **Вирусная бомба / мгновенное заражение площади** | Анти-цель «гриферский инструмент». Распространение всегда требует времени |
| **Своя руда** | Конфликт с техномодами, лишняя генерация мира |
| **Своя система энергии** | Принимаем FE, не изобретаем |
| **Новые заражённые мобы как сущности** | Состояние вместо сущности. Совместимость и производительность |
| **Боссы** | Не тот жанр |
| **Своё измерение** | Не нужно для концепции |
| **Инверсия управления, пропажа предметов** | Ощущается как баг (см. [04-SYMPTOMS.md](04-SYMPTOMS.md)) |
| **Рандомные разблокировки исследований** | Анти-цель «непрозрачная случайность» |
| **Мини-игры с реакцией/таймингом** | Не подходит жанру, плохо на лагах |
