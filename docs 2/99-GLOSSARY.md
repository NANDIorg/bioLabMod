# 99 — Глоссарий

Три колонки: как это называется для игрока, что это в реальной биологии, как это
называется в коде. Нужен, чтобы в текстах мода, в документации и в коде не
расходились термины.

## Соглашения о неймспейсах

```
Мод id:            biohazard
Пакет:             dev.projectbiohazard
API-артефакт:      dev.projectbiohazard:biohazard-api
Реестры:           biohazard:gene, biohazard:symptom, ...
Теги хостов:       biohazard:host/<профиль>
Теги материалов:   c:ingots/<металл>  (чужие, не свои)
```

Категории генов в id — через слэш: `biohazard:tropism/mammalian`,
`biohazard:symptom/fever`, `biohazard:reg/kill_switch`.

## Термины, которые НЕ используем

| Не говорим | Говорим | Почему |
|------------|---------|--------|
| «Бактерия» про вирус | Вирус / патоген / штамм | Смешивает понятия |
| «ДНК вируса» в общем случае | Геном, цепь | Бывают и РНК-вирусы |
| «Вылечить» про вакцину | Привить, вакцинировать | Вакцина не лечит |
| «Иммунитет» про защиту костюма | Защита, защитный фактор | Разные механики |
| «Заражённый моб» как отдельное существо | Моб в состоянии заражения | У нас это состояние, не сущность |
| «Мутант» | Вариант, штамм | «Мутант» уводит в фэнтези |
| «Вирусная бомба», «биооружие» в UI | Развёртывание, распылитель | Тон мода — лабораторный, не военный |
