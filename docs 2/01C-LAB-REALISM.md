# 01C — Реалистичность: как это делают в настоящей лаборатории

Требование заказчика: «чтоб в меру реалистично было, как в реальной жизни
примерно проводятся такие исследования и создания».

Хорошая новость: **настоящий лабораторный цикл сам по себе — отличная игровая
цепочка**. Он уже состоит из последовательных шагов с зависимостями, расходниками,
измерениями и рисками. Нам почти не нужно ничего выдумывать — достаточно честно
перенести его структуру и абстрагировать детали.

**Граница абстракции:** мы моделируем **процедуры и зависимости между ними**, но
не химию. Никаких реальных реагентов, концентраций, протоколов или
последовательностей. Названия — реальные, числа и режимы — игровые и генерируются
от сида мира. Это игра про логику лабораторной работы, а не инструкция.

---

## 1. Реальный цикл работы с вирусом → механика мода

### Этап 1. Сбор и выделение (в реальности: field sampling & isolation)

| В реальности | В моде |
|--------------|--------|
| Мазок, кровь, биопсия, образцы среды (вода, почва) | Набор для образцов: мазок с моба, кровь, ткань, вода, почва, растение |
| Транспорт в холодовой цепи, вирусная транспортная среда | **Образец деградирует без охлаждения.** Нужен термобокс в походе и криохранилище на базе |
| Посев на клеточную культуру или в куриные эмбрионы | **Инокуляция клеточной линии** — см. раздел 2. Куриные эмбрионы = ранняя дешёвая альтернатива (яйца!) |
| Наблюдение ЦПД (цитопатический эффект) — клетки гибнут | **Под микроскопом видно, что культура погибает** — первый признак, что вирус растёт. Красивый и понятный фидбек |
| Титрование методом бляшек (PFU/мл) | **Титр образца — реальная числовая величина.** Измеряется бляшечным анализом |
| Серийные разведения | Разведение образца: меньше титр, больше объём |

### Этап 2. Характеристика (в реальности: characterization)

| В реальности | В моде |
|--------------|--------|
| Электронная микроскопия: морфология | Микроскопия: шасси, длина цепи |
| Проба с эфиром/растворителем: есть ли оболочка | Тест на оболочку |
| Термостабильность | Тест нагревом |
| Панель клеточных линий разных видов → спектр хозяев | **Панель хозяев** — ключевой анализ. Нужны культуры нескольких видов! |
| ПЦР с праймерами | **Амплификация — только если есть праймер.** См. раздел 3 |
| Рестрикционный анализ + гель-электрофорез | **Электрофорез:** число генов и их размеры |
| Серология, ИФА, реакция нейтрализации | Иммуноанализ: родство с изученными штаммами |
| Секвенирование | Секвенатор: точно, по одному гену за цикл |

### Этап 3. Молекулярная работа (в реальности: cloning & engineering)

| В реальности | В моде |
|--------------|--------|
| Выделение нуклеиновой кислоты | Выделение гена в картридж |
| ПЦР-амплификация нужного фрагмента | Амплификация картриджа (**нужен праймер**) |
| Рестрикция ферментами | Операция разреза при вставке |
| Клонирование в плазмидный вектор | **Плазмида** — носитель для переноса гена. См. раздел 4 |
| Трансформация в E. coli, рост колоний, отбор по антибиотику | **Бактериальный культиватор:** растишь колонии, отбираешь удачные. Объясняет случайность результата |
| Проверка секвенированием | Контрольное секвенирование после сборки |
| Сайт-направленный мутагенез | Точная правка (T3) |
| CRISPR/Cas для направленного редактирования | Нуклеазная матрица (T3) |
| Gibson/Golden Gate сборка из синтезированных олигонуклеотидов | **Синтез de novo (T4):** синтезируешь фрагменты и собираешь цепь |
| Обратная генетика: полноразмерный клон → трансфекция → «спасение» живого вируса | **Процедура спасения (rescue):** финальный шаг синтеза. **Может провалиться** — драматичный момент |

### Этап 4. Фенотипирование (в реальности: phenotyping)

| В реальности | В моде |
|--------------|--------|
| Кривые роста в культуре | График роста титра — измеряемая характеристика |
| Анализ связывания с рецептором | Тест связывания: аффинность к рецептору численно |
| Модели на животных (мыши, хорьки, свиньи) | Пассажная камера с животными |
| **Исследования передачи на хорьках: клетки прямого контакта vs разделённые сетками (аэрозоль)** | **Камера передачи:** два отсека — с контактом и разделённые. Прямо определяет, какие векторы работают. Это буквально как делают в реальности |
| Оценка патогенности | Измерение вирулентности, летальности |
| Серийный пассаж для адаптации | Направленная эволюция (ядро T2) |

### Этап 5. Вакцины и препараты

| В реальности | В моде |
|--------------|--------|
| Инактивация формалином/бета-пропиолактоном/нагревом | Инактивированная вакцина |
| Аттенуация пассажем через неродного хозяина, холодовая адаптация | Живая ослабленная вакцина через пассаж |
| Деоптимизация кодонов (современный метод аттенуации) | T3-операция ослабления без пассажа |
| Субъединичные и векторные вакцины на выбранный антиген | Субъединичная вакцина по выбранному гену |
| Реакция нейтрализации: измерение титра антител | Измерение силы иммунитета |
| Challenge-исследования: вакцинировал → заразил → выжил? | **Проверка вакцины:** вакцинируешь подопытное животное и заражаешь. Единственный способ узнать, работает ли |
| Скрининг антивирусных, подбор, пассаж на резистентность | Разработка антивирусов, выработка резистентности |

### Этап 6. Биобезопасность

| В реальности | В моде |
|--------------|--------|
| Уровни BSL-1…BSL-4 | Полностью перенесено, см. [07-CONTAINMENT.md](07-CONTAINMENT.md) |
| Ламинарный шкаф, асептическая техника | Биобокс + стерильность помещения |
| Автоклавирование отходов, поток отходов | Автоклав, утилизатор биоотходов |
| Холодовая цепь: −80 °C, жидкий азот | Криохранилище |
| Лабораторный журнал, СОПы | Карты протоколов, Кодекс, журнал инцидентов |
| Оценка риска перед работой | Класс опасности штамма, требуемый BSL |
| Контроль работ двойного назначения | Флавор: предупреждения системы при создании класса IV–V |

**Вывод: 90% геймплея мода — это честно перенесённая структура настоящей
лабораторной работы.** Остальное — абстракция там, где реальность нечитаема.

## 2. Клеточные культуры: живой ресурс и главный «реалистичный» апгрейд

В реальности **вирус нельзя вырастить в пробирке с питательным бульоном.**
Вирусу нужны живые клетки. Это самое важное, что я упустил в первой версии
дизайна, и это даёт мод сразу три вещи: инфраструктуру, зависимость от
исследования мира и честный межвидовой барьер.

### Как это работает

```
Образец ткани вида X  →  Клеточная линия вида X  →  субстрат для вируса
       (из моба)            (живая, требует ухода)      (растёт, только если
                                                         у вируса есть тропизм
                                                         к рецептору этого вида)
```

### Механика

| Свойство | Как работает |
|----------|--------------|
| **Получение** | Образец ткани от моба (живого или убитого) → в инкубаторе вырастает первичная культура |
| **Видовая принадлежность** | Линия несёт **рецепторы своего вида**. Вирус растёт в ней, только если имеет соответствующий тропизм |
| **Первичная культура** | Живёт ограниченное число пассажей (реально: предел Хейфлика). Потом гибнет. Нужно обновлять из новой ткани |
| **Иммортализованная линия (T3)** | Делится бесконечно, не требует обновления. Серьёзный апгрейд качества жизни |
| **Уход** | Требует питательной среды и температуры. **Нет подачи среды → культура гибнет.** Это настоящая инфраструктура с расходом |
| **Контаминация** | Культура в нестерильных условиях заражается бактериями и гибнет. См. раздел 5 |
| **Банк линий** | Блок «Банк клеточных культур»: хранение и поддержание нескольких линий. Центральный блок лаборатории |

### Почему это очень хорошо для геймплея

1. **Это и есть «необходимость в инфраструктуре»,** которую просил заказчик:
   живые культуры нужно непрерывно поддерживать, иначе вся лаборатория встаёт.
2. **Панель хозяев становится настоящей.** Хочешь узнать, заражает ли твой штамм
   приматов? Нужна **приматная клеточная линия**. А её надо откуда-то взять.
   Это драматичный момент: ты берёшь образец своей собственной ткани.
3. **Честный межвидовой барьер без искусственных запретов.** Вирус физически не
   растёт в культуре вида, к которому у него нет тропизма. Игрок сам это видит.
4. **Причина исследовать мир.** Линии экзотических видов (фауна Нижнего мира,
   Энд) требуют туда идти.
5. **Куриные эмбрионы как дешёвый вход.** Реальный метод (так до сих пор растят
   вакцину от гриппа). В моде: **обычные яйца** — дёшево, доступно на T1, но
   работает только для штаммов с птичьим тропизмом. Отличный онбординг: яйца
   у игрока уже есть.

## 3. Праймеры: чтобы копировать ген, его надо сначала прочитать

Самая элегантная реальная зависимость, которую стоит перенести дословно.

В реальности: **ПЦР невозможна без праймеров, а праймеры нельзя спроектировать,
не зная последовательности.** То есть прочитать — обязательное условие, чтобы
размножить.

### Механика

```
Ген неизвестен
  └─> нельзя амплифицировать. Есть только то количество, которое добыл
      └─> СЕКВЕНИРОВАНИЕ (дорого, медленно)
          └─> данные последовательности
              └─> СИНТЕЗ ПРАЙМЕРА (предмет, одноразовое вложение)
                  └─> теперь ген можно амплифицировать дёшево и бесконечно
```

### Почему это важно

- **Секвенирование перестаёт быть «просто посмотреть».** Это инвестиция с
  постоянной отдачей: прочитал ген один раз — получил к нему доступ навсегда.
- **Дефицит материала на раннем этапе становится реальным.** Нашёл редкий ген в
  заброшенной лаборатории, но не отсеквенировал → у тебя ровно один картридж, и
  если операция его испортит, он потерян. **Это заставляет бэкапить и бояться.**
- **Прямая связь «изучение → возможности»,** которую просил заказчик, встроена в
  саму механику, а не в дерево исследований.
- Праймер можно **передать другому игроку** — знание как торгуемый актив.

### Связанная реальная деталь: праймер неспецифичен

Праймер, спроектированный на ген, работает и на **близкие варианты того же
гена** (с падением эффективности пропорционально различию). Это реально и
геймплейно удобно: не нужно секвенировать каждый мутант заново.

## 4. Плазмиды и бактериальное клонирование: откуда берётся случайность

Это объясняет «на T2 ты не контролируешь позицию» не условностью, а настоящим
механизмом.

### Реальная цепочка

1. Ген вставляют в **плазмиду** (кольцевой вектор)
2. Плазмиду вводят в **бактерию** (трансформация)
3. Бактерии растят на среде с **антибиотиком** — выживают только те, кто взял плазмиду
4. Получают **колонии**, каждая — свой клон
5. Колонии **проверяют** и выбирают правильную
6. Из плазмиды ген переносят в вирусный геном

### Механика в моде

| Блок | Роль |
|------|------|
| **Сборщик плазмид** | Ген + плазмидный остов → готовая конструкция |
| **Бактериальный культиватор** | Растит колонии. Выдаёт **несколько результатов разного качества** |
| **Селективная среда (антибиотик)** | Расходник, отсекает неудачные |
| **Проверка колоний** | Быстрый анализ: какая колония несёт правильную вставку |

**Вот откуда берётся случайность на T2:** ты получаешь 3–5 колоний, каждая со
своим вариантом вставки (разная позиция, разная ориентация, часть повреждена).
Ты проверяешь их и **выбираешь лучшую из того, что получилось**. Это не «рандом
наказал» — это настоящая процедура отбора клонов, и игрок в ней участвует.

На T3 нуклеазная матрица позволяет вставлять направленно и обходиться без
колоний. На T4 синтез даёт точную цепь целиком.

**Это делает прогрессию контроля не абстрактной, а объяснимой.** Отличный
результат: реализм прямо усилил геймплей.

## 5. Стерильность работает в обе стороны

Важная реальная деталь, которую почти никогда не используют в играх.

В настоящей лаборатории герметичность и чистота защищают **не только мир от
вируса, но и культуру от мира**. Бактериальная или грибковая контаминация
клеточных культур — повседневная головная боль любой биолаборатории.

### Механика

```
Загрязнение помещения (бактерии, споры, пыль) → риск контаминации культур
Контаминированная культура → погибла, эксперимент потерян, результаты недостоверны
```

| Защита | Эффект |
|--------|--------|
| Биобокс (ламинарный шкаф) | Работа с культурой внутри бокса — почти нулевой риск |
| Чистота помещения | Отдельный показатель: уровень бактериального фона |
| HEPA-фильтрация | Снижает фон |
| Автоклавированные расходники | Стерильные среды и посуда |
| Антибиотик в среде | Расходник, снижает риск, но **не устраняет** |
| Дезинфекция поверхностей | Регулярная обработка помещения |
| Вход через шлюз | Меньше заноса извне |

### Почему это ценно

- **Сдерживание становится двусторонним и поэтому вдвойне осмысленным.** Игрок
  строит герметичную лабораторию не только из страха, но и потому что иначе
  ничего не работает. **Это сильнейшая мотивация строить инфраструктуру** —
  гораздо лучше, чем просто наказание.
- Появляется различие между «грязной» и «чистой» зоной лаборатории, как в
  настоящих комплексах.
- Это объясняет, зачем автоклав, шлюз и фильтры нужны **уже на T1–T2**, до
  появления опасных штаммов.

## 6. Титр: вирус измеряется в количестве

В реальности любой эксперимент начинается с того, что ты знаешь **титр** своего
препарата (PFU/мл). Без этого результаты несопоставимы.

| Механика | Как работает |
|----------|--------------|
| **Титр образца** | Числовая величина, свойство образца (`DataComponent`) |
| **Бляшечный анализ** | Измеряет титр. Расходует часть образца и клеточную культуру |
| **Разведение** | Понижает титр, увеличивает объём. Нужно для точных экспериментов |
| **Наращивание в биореакторе** | Повышает титр и объём. Нужно для масштабных применений |
| **Доза при заражении (MOI)** | Параметр протокола. Слишком мало → не заразилось. Слишком много → хост умирает сразу, результат бесполезен |
| **Деградация** | Титр падает без холода, быстрее для `structure/enveloped` |

Это соединяет реализм с уже существующей дозовой механикой из
[02-INFECTION-MODEL.md](02-INFECTION-MODEL.md): низкий титр = низкая доза = может
не заразить. И объясняет, зачем нужен биореактор: **одного флакона не хватит,
чтобы вакцинировать деревню**.

**Антискука:** титр показан прямо в тултипе образца, а в протоколах есть кнопка
«привести к стандартной дозе» — машина сама разведёт. Игрок управляет титром
только когда хочет.

## 7. Где мы сознательно отходим от реализма

Честный список компромиссов — чтобы при реализации не спорить каждый раз.

| Реальность | В моде | Почему |
|------------|--------|--------|
| Нуклеотидные последовательности | Гены как неделимые объекты | Последовательности нечитаемы и неиграбельны |
| Белки, фолдинг, домены | Нет | Слишком глубокий уровень |
| Эксперимент длится недели | Минуты–игровые дни | Иначе невозможно играть |
| Нужна команда и миллионы | Один игрок | Это игра |
| Десятки типов клеточных линий | Одна линия на вид/профиль | Читаемость |
| Статистика, повторности, контроли | Нет формальной статистики | **[решение автора]** Обсуждалось: «нужны 3 повторности» = скука. Отклонено |
| Регуляторные согласования, этика | Только флавор-предупреждения | Не геймплей |
| Вирус не «даёт способности» | Полезные симптомы дают | Игровая условность, нужная заказчику |
| Эволюция идёт поколениями | Ускорена в десятки раз | Иначе не видно |
| Реальные названия препаратов и методик в деталях | Обобщённые игровые | Сознательно: мод не должен выглядеть инструкцией |

## 8. Как реализм кладётся на тиры

Проверка: соответствует ли прогрессия мода реальной истории развития методов?
Да, и это приятный бонус — игрок проходит через историю вирусологии.

| Тир | Реальный исторический уровень | Доступные методы |
|-----|-------------------------------|------------------|
| **T0** | Конец XIX в. | Наблюдение, сбор образцов, микроскопия, фильтрация |
| **T1** | 1930–1950-е | Куриные эмбрионы, первичные клеточные культуры, титрование, инактивированные вакцины, пассаж |
| **T2** | 1970–1990-е | Рестрикция, электрофорез, плазмидное клонирование, ПЦР, праймеры, секвенирование по одному гену, живые аттенуированные вакцины |
| **T3** | 2000–2015 | Обратная генетика, сайт-направленный мутагенез, CRISPR, субъединичные и векторные вакцины, биореакторы, иммортализованные линии |
| **T4** | 2015–настоящее и дальше | Полный синтез генома de novo, химерные конструкции, универсальные вакцины, генная терапия |

Это даёт прогрессии естественную и внутренне логичную форму: **каждый тир — это
не «числа больше», а «эпоха методов шире»**. И это ровно то, что просил
заказчик: нельзя сразу сделать крутой вирус, потому что в твою эпоху методов
таких инструментов просто нет.

## 9. Что обязательно проверить тестами

- Вирус не растёт в клеточной линии без соответствующего тропизма
- Первичная культура погибает через заданное число пассажей, иммортализованная — нет
- Прекращение подачи среды убивает культуру через заданное время
- Амплификация невозможна без праймера к этому гену
- Праймер работает на близких вариантах гена со сниженной эффективностью
- Секвенирование гена открывает возможность синтеза праймера к нему
- Бактериальное клонирование выдаёт несколько вариантов колоний, среди которых
  есть хотя бы один пригодный с заданной вероятностью
- Титр падает без холодного хранения, быстрее для оболочечных штаммов
- Бляшечный анализ расходует образец и культуру
- Загрязнение помещения повышает риск контаминации культуры
- Работа в биобоксе почти исключает контаминацию
- Процедура спасения (rescue) при синтезе de novo может провалиться с заданной
  вероятностью, и неудача не уничтожает проект целиком
- Камера передачи с разделёнными отсеками корректно различает контактные и
  воздушные векторы
