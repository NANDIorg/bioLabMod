# 05 — Заражение мира: загрязнение, порча, еда, деконтаминация

Требование заказчика: вырвавшийся вирус заражает окружающий мир и животных, еда
портится и становится опасной. Это самая опасная для производительности часть
мода, поэтому дизайн здесь подчинён техническому ограничению.

**Главное решение: три уровня детализации.** Чем дальше от игрока — тем грубее и
дешевле.

```
Уровень 1: ПОЛЕ ЗАГРЯЗНЕНИЯ   — на чанк, O(1), ленивый распад, всегда активно
Уровень 2: ПОРЧА БЛОКОВ        — настоящие изменения блоков, только загруженные чанки, строгий бюджет
Уровень 3: АТМОСФЕРА           — чисто клиентский рендер, нулевая цена на сервере
```

---

## 1. Уровень 1: поле загрязнения

### Структура данных

Аттачмент на `LevelChunk`:

```java
ChunkContamination {
    // Обычно 1-2 записи. Жёсткий лимит, слабейшие вытесняются.
    Map<UUID strainId, Entry> strains;   // максимум 4 (конфиг)

    record Entry(
        short concentration,   // 0..10000, фиксированная точка
        long  lastUpdateTick,  // для ленивого распада
        byte  hotspotX, hotspotY, hotspotZ  // одна точка-эпицентр для визуала
    ) {}
}
```

Размер: ~24 байта на штамм на чанк. На 10 000 загрязнённых чанков — меньше
мегабайта. Приемлемо.

### Ленивый распад — ключевой трюк производительности

**Мы никогда не тикаем чанки для распада.** Концентрация вычисляется при чтении:

```java
float current(Entry e, long now, Strain s, ChunkEnvironment env) {
    long dt = now - e.lastUpdateTick;
    float halfLife = s.phenotype().envHalfLifeTicks() * env.modifier();
    return e.concentration * (float) Math.pow(0.5, dt / halfLife);
}
```

Следствие: **выгруженный чанк стоит ноль**. Игрок уходит на месяц — загрязнение
честно распадается, но не потратило ни одного тика. Это и есть правильная
архитектура.

`env.modifier()` учитывает условия чанка: солнце (если нет `env/uv_resistant` —
распад ×5 днём), дождь (смывает, но разносит в соседние чанки ниже по склону),
биом (жара/холод против соответствующих генов), под землёй (распад медленнее).

### Индекс загрязнённых чанков

Чтобы никогда не сканировать мир — `SavedData` уровня:

```java
ContaminationIndex {
    LongSet contaminatedChunks;           // ChunkPos.asLong()
    PriorityQueue<Long> spreadQueue;      // приоритет по концентрации
    Map<Long, Integer> corruptionProgress;// прогресс порчи блоков по чанку
}
```

### Растекание

Раз в 100 тиков, **строгий бюджет 64 чанка за проход**, круговая очередь:

```
взять до 64 чанков из очереди (приоритет — высокая концентрация)
для каждого:
    c = current(...)
    если c < порогаИсчезновения: удалить из индекса, продолжить
    для 4 соседей по горизонтали (+вниз для fluid-штаммов):
        передать c × spreadRate × factor(вектор, препятствия)
    // аэрозоль растекается широко, soilborne — только по земле,
    // fluid — по течению воды вниз
```

Важно: растекание **не требует**, чтобы чанк был загружен. Мы работаем с данными
чанка, а не с блоками. Для незагруженных — используется кэш данных чанка из
региона (читаем аттачмент без полной загрузки чанка, либо держим агрегат в
`ContaminationIndex`). **[решение автора документа]** Если API не позволяет читать
аттачмент без загрузки — дублируем концентрацию в `ContaminationIndex`, и он
становится источником истины, а аттачмент чанка — кэшем. Это надо проверить
первым делом при реализации.

## 2. Уровень 2: порча блоков

Когда чанк держит высокую концентрацию достаточно долго — мир начинает меняться
по-настоящему. Это то, что игрок запомнит.

### Стадии порчи чанка

| Стадия | Условие | Что происходит |
|--------|---------|----------------|
| 0 — чистый | `C < 500` | — |
| 1 — следы | `C ≥ 500` | Декор: налёт на блоках, редкие частицы. Блоки не меняются, только вариант текстуры |
| 2 — поражённый | `C ≥ 2000` × 1 день | Трава → `infected_grass`, листва → `blighted_leaves`, посевы вянут, вода темнеет |
| 3 — заражённый | `C ≥ 5000` × 3 дня | Появляются наросты, биолюминесцентные жилы, споровые стебли, животные спавнятся заражёнными |
| 4 — мёртвая зона | `C ≥ 8000` × 7 дней | Земля → `necrotic_soil`, деревья гибнут, вода → `tainted_water`, спавн враждебных заражённых, свой эмбиент |

Переход назад происходит при падении концентрации — **порча обратима**, но
медленно (стадия назад требует ×2 времени). Соответствует анти-цели
«необратимая потеря мира».

### Правила трансформации — датапаком

```json
{
  "stage": 3,
  "rules": [
    { "from": "#minecraft:dirt",        "to": "biohazard:infected_soil",  "weight": 10 },
    { "from": "minecraft:grass_block",  "to": "biohazard:infected_grass", "weight": 10 },
    { "from": "#minecraft:leaves",      "to": "biohazard:blighted_leaves", "weight": 6 },
    { "from": "#minecraft:crops",       "to": "biohazard:withered_crop",  "weight": 15 },
    { "from": "minecraft:water",        "to": "biohazard:tainted_water",  "weight": 4 },
    { "place_on": "#biohazard:infected_soil", "place": "biohazard:spore_stalk", "weight": 2 }
  ]
}
```

Аддон полностью переопределяет внешний вид порчи, добавляет свои блоки,
обрабатывает блоки других модов. Ноль кода.

### Жёсткие ограничения — защита от лагов и гриферства

| Ограничение | Значение по умолчанию | Зачем |
|-------------|----------------------|-------|
| Блоков за проход на уровень | 16 | Производительность |
| Период прохода | 100 тиков | Производительность |
| Только загруженные чанки | да | Нельзя менять блоки в выгруженных |
| Чёрный список блоков | тег `biohazard:corruption_immune` | Защита: все блоки-контейнеры, машины, рельсы, спавнеры, обсидиан, бедрок, любой блок с BlockEntity по умолчанию |
| **Блоки с инвентарём никогда не трансформируются** | да | Нельзя терять предметы игрока |
| Уважение клейм-модов | да, если установлены | Чужая база не портится |
| Радиус от спавна | конфиг (по умолчанию 0 = нет защиты) | Опция для серверов |
| Общий тумблер | `worldCorruption: true/false` | Можно играть только с механикой здоровья |

**Правило без исключений: порча никогда не уничтожает предметы игрока и никогда
не ломает блок с инвентарём или BlockEntity.** Это прямая анти-цель.

### Журнал изменений для откатa

Каждая трансформация пишется в компактный лог на чанк (`from → to`, позиция).
Деконтаминация читает лог и **восстанавливает исходные блоки**. Лог ограничен
по размеру; при переполнении восстановление идёт по обратным правилам датапака
(менее точно, но работает). Это даёт честную обратимость.

## 3. Уровень 3: атмосфера (клиент)

Нулевая цена на сервере, максимальная отдача по ощущению. Клиент знает
концентрацию в своём чанке и соседних (приходит в компактном пакете при смене
чанка) и рисует:

- **Цвет и плотность тумана** — от лёгкой дымки до густого смога. Цвет из датапака штамма
- **Сдвиг цветов** — обесцвечивание, зеленоватый/багровый оттенок
- **Частицы в воздухе** — споры, пыль, мошкара
- **Эмбиент** — низкий гул, шёпот, жужжание; приглушение обычных звуков природы
- **Нарастающее искажение по краям экрана** при высокой дозе у игрока
- **Счётчик дозиметра** — тикающий звук, как у счётчика Гейгера, частота ∝ концентрации

Дозиметр со звуком — самый эффективный инструмент передачи опасности. Дёшево и
очень работает.

## 4. Еда, вода и предметы

Требование заказчика: «еда с собой становится непригодной и опасной».

### Загрязнение предметов

`DataComponent` на `ItemStack`:

```java
record ItemContamination(UUID strainId, short level, long sampledTick) {}
```

Как предмет загрязняется:

1. **Лежит в загрязнённом чанке** (в инвентаре игрока, в сундуке, на земле) —
   накапливает загрязнение раз в N тиков, пропорционально концентрации
2. **Получен от заражённого хоста** — мясо, кожа, яйца, молоко, шерсть от
   заражённого моба загрязнены сразу, уровень ∝ вирусной нагрузке хоста
3. **Собран с заражённого растения** — урожай с заражённого посева
4. **Контакт с заражённым игроком** (`transmission/fomite`)
5. **Налит из загрязнённого источника** — вода, котёл

### Что это даёт игроку

| Действие | Результат |
|----------|-----------|
| Съесть загрязнённую еду | Доза экспозиции (8.0 × уровень). **Еда не исчезает из игры, она становится риском** |
| Приготовить на огне | Загрязнение ×0.15. Термолабильные штаммы погибают, `env/thermostable` — нет |
| Положить в **герметичный контейнер** | Загрязнение не растёт. ← смысл блока |
| Положить в **холодильник** | Загрязнение не растёт, существующее медленно падает |
| Обработать в **автоклаве** | Полная стерилизация предмета |
| Проверить **полевым тестером** | Увидеть уровень загрязнения и штамм (если известен) |
| Не проверять | Рулетка. Тултип покажет только «⚠ подозрительно», если тестера нет |

**Ключ к тому, чтобы это не бесило:** визуальный индикатор обязателен и дёшев.
Загрязнённая еда имеет **явно отличимую иконку/оверлей и предупреждение в
тултипе**. Игрок никогда не должен съесть опасное случайно, если у него есть
базовые знания. Скрытым остаётся только *какой именно* штамм.

Готовка как дезактивация — элегантно: она уже есть в игре, и теперь у неё
появляется второй смысл. И это создаёт настоящую разницу между штаммами с
`env/thermostable` и без.

## 5. Вода

Вода — мощнейший вектор, и в Minecraft она течёт.

- Источник воды в загрязнённом чанке становится загрязнённым
- `transmission/fluid` позволяет загрязнению **идти по течению** в соседние
  чанки вниз по потоку (растекание учитывает направление потока)
- Бутылка/котёл наследуют загрязнение
- **Колодец деревни** — особая точка: загрязнение колодца заражает всю деревню
  через потребление. И это же — точка для лечения: деконтаминация колодца
  останавливает вспышку
- Океан разбавляет: загрязнение в океанском биоме падает быстро (большой объём),
  кроме `env/aquatic_stable`
- Рыба из загрязнённой воды — загрязнена

## 6. Деконтаминация: как чистить

Это обязательная часть, без неё мод становится необратимо-разрушительным.
Инструменты по возрастанию масштаба:

| Метод | Тир | Площадь | Скорость | Цена | Побочки |
|-------|-----|---------|----------|------|---------|
| **Ручной распылитель** | T1 | 3×3×3 | Мгновенно | Расход реагента | Нет |
| **УФ-излучатель** | T2 | 7×7×7, только прямая видимость | Медленно, непрерывно | Энергия | Не работает против `env/uv_resistant`, портит посевы |
| **Дезинфекционный туман** | T2 | Чанк | Средне | Реагент + энергия | Урон живности в зоне |
| **Контролируемый выжиг** | T1 | По площади | Быстро | Дёшево | **Уничтожает ландшафт.** Работает против всего, кроме `spore_coat` |
| **Автоклав** | T2 | Предметы | Мгновенно | Энергия | — |
| **Дезактивационный душ** | T2 | Игрок/костюм | Мгновенно | Вода + реагент | Обязателен при выходе из BSL-3+ |
| **Станция ремедиации** | T3 | Радиус 64, непрерывно | Очень медленно (дни) | Энергия + биомасса | Автономная уборка большой зоны |
| **Ремедиационные бактерии** | T3 | Распространяются сами | Медленно | Производство | ⚠️ Это тоже живой организм. Может мутировать. Ирония встроена в дизайн |
| **Полный стерилизующий залп** | T4 | Радиус 128 | Быстро | Очень дорого | Убивает **всю** живность и растительность в зоне. Мёртвая, но чистая земля |

### Правила честности

- Чистка **всегда** возможна, но стоимость растёт нелинейно с масштабом. Авария в
  зоне 1000 чанков — это проект на недели игрового времени
- Восстановление блоков идёт по журналу изменений → ландшафт возвращается
- Нельзя почистить область, пока в ней есть **живой резервуар**: заражённые
  зомби или заражённое поголовье будут вновь загрязнять. Сначала источник, потом
  уборка. Это учит эпидемиологии естественным путём
- Ремедиационные бактерии, которые сами мутируют, — отличная тематическая петля:
  решение проблемы может стать проблемой

## 7. Новая структура: заброшенная лаборатория

Генерируемая структура, которая служит сразу трём целям: мотивация исследовать
мир, источник T3-генов, и повествование без текста.

- Подземный комплекс (3–4 уровня) с остатками оборудования
- Внутри: **активная зона загрязнения** с природным опасным штаммом
- Заражённые мобы внутри (уже с интересными симптомами — живая демонстрация)
- Лут: схемы машин, образцы с редкими генами, компоненты, **исследовательские
  записи** (дают очки исследований напрямую — хороший онбординг)
- Разные варианты по классу опасности: от небольшого BSL-2 бокса до
  полномасштабного прорванного BSL-4 комплекса (поздняя игра, требует костюма)
- **Опасность пропорциональна награде, и она видна снаружи:** у входа заражённая
  земля и мёртвые деревья — игрок понимает, во что лезет

Это даёт причину идти в мир, которую просил заказчик, и работает как
предупреждение-притча: вот что бывает, когда не справились со сдерживанием.

## 8. Что обязательно проверить тестами

- Ленивый распад математически совпадает с пошаговым распадом (критичный тест)
- Выгруженный чанк не потребляет тиков, но при возврате концентрация корректна
- Бюджет растекания никогда не превышается, даже при 100 000 загрязнённых чанков
- Бюджет трансформации блоков соблюдается
- Блок с инвентарём **никогда** не трансформируется (тест на всех ванильных типах)
- Тег `corruption_immune` соблюдается
- Журнал изменений позволяет полное восстановление
- Загрязнение предмета сохраняется при переносе между инвентарями и миром
- Готовка снижает загрязнение, но не для `env/thermostable`
- Герметичный контейнер защищает предметы
- Вода переносит загрязнение по течению только с `transmission/fluid`
- Деконтаминация не может очистить чанк при наличии живого резервуара в нём
- Клиент не получает данных о штаммах, которые игрок не исследовал
