# Project Biohazard — документация

Мод для Minecraft Java Edition: инженерия вирусов, эпидемиология, биобезопасность.

**Платформа:** NeoForge 1.21.x, Java 21
**Масштаб:** крупный мод (20–40 часов прогрессии), живёт рядом с техномодами, не заменяет их
**Режим:** сингл и небольшие кооп-сервера (2–5 игроков)
**Интеграция:** Forge Energy + теги металлов как база; Create и Mekanism/Thermal — опционально

---

## Как читать эту документацию

Документы идут от «что это за игра» к «как это устроено внутри». Если ты садишься
реализовывать — читай `10-ARCHITECTURE.md` и `15-ROADMAP.md`, но сначала
обязательно `00-VISION.md` и всю тройку `01`, `01B`, `01C`, иначе половина
технических решений будет выглядеть произвольной.

**Если читаешь только один документ — читай [01B](01B-GENOME-ENGINEERING.md).**
Там лежит ответ на главный вопрос мода: почему создавать вирус интересно.

## Статус

Документация описывает **целевой дизайн**, а не текущее состояние кода. Кода пока нет.
Все числа помечены как настраиваемые и подлежат балансировке на практике — они нужны,
чтобы задать порядок величин, а не как истина.

Решения, принятые мной без согласования с заказчиком, помечены в тексте как
**[решение автора документа]** — их стоит перечитать критически. Все они собраны
в одном списке в [99-OPEN-QUESTIONS.md](99-OPEN-QUESTIONS.md).

## Принятые решения по проекту

| | |
|---|---|
| **Охват** | Делаем мод полностью, сколько потребуется. T3, T4 и терраформирование входят |
| **Режим публикации** | Пока для себя. API для аддонов и `en_us.json` всё равно делаем |
| **Текстуры** | Рисует Codex по спецификациям. Пилот из 5 текстур — первая задача |
| **Модели** | Генерация JSON кодом (ванильный формат + GeckoLib geo). Не Blender — формат только кубоидный |
| **Исследования в кооперативе** | Общие на мир |
| **Сложность по умолчанию** | Жёсткая: летальность, хронические последствия и порча мира включены |
| **Жители** | Болеют теми же штаммами, что игрок (один приматный рецептор). Деревня — полноценный узел эпидемии |
| **Смерть** | Не обнуляет хронические последствия. Снимаются только генной терапией T4 |
