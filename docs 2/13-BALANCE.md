# 13 — Баланс, числа, конфигурация

⚠️ **Все числа здесь — отправная точка, а не истина.** Они нужны, чтобы задать
порядок величин и чтобы реализация не придумывала их заново. Настоящий баланс
получится только на прохождениях.

Правило: **любое число из этого документа должно быть в конфиге или датапаке.**
Хардкод чисел баланса — повод отклонить PR.

## 1. Единицы и масштабы времени

| Величина | Значение |
|----------|----------|
| Игровой день | 24 000 тиков (20 минут) |
| Период проверки инфекции | 20 тиков (1 сек) |
| Вирусная нагрузка | 0–1000 |
| Концентрация загрязнения | 0–10000 |
| Титр образца | 0–10000 |
| Доза экспозиции | 0–100, порог обычно 20–60 |
| Стабильность генома | 0–100 |
| Экспрессия гена | 0–100 (вычисляется) |

**Ориентир по темпу болезни:** типичная болезнь среднего штамма от заражения до
исхода — **2–4 игровых дня** (40–80 минут реального времени). Достаточно долго,
чтобы успеть отреагировать, достаточно быстро, чтобы видеть результат за сессию.

### Источники дозы (единиц/сек)

| Источник | Значение |
|----------|----------|
| Загрязнение, концентрация C | `C / 10000 × 1.0` |
| Рядом заражённый (острая стадия), дист. d | `0.5 × shedding / max(1, d²)` |
| Открытая культура в руках | 3.0 |
| Заражённая еда (единоразово) | 8.0 × уровень загрязнения |
| Заражённая вода (единоразово) | 6.0 |
| Укус заражённого (bloodborne) | 10.0 |
| Укус переносчика | 12.0 |
| Разбитая пробирка / авария | 25.0 |
| Снятие незадезактивированного костюма | 15.0 |

**Проверка на вменяемость:** без защиты в чанке с концентрацией 5000 (стадия 3)
доза копится 0.5/сек → порог 30 за ~60 секунд. В костюме хазмат (0.85 от
аэрозоля) → ~7 минут. В костюме давления (0.995) → ~3.3 часа. Это читаемый и
справедливый градиент.

## 3. Стабильность генома

```
scarPenalty               = 2.0  на позицию
occupiedPositionPenalty   = 0.8  на позицию
overlapPenalty            = 15.0 на перекрытие
mutationLoadPenalty       = 1.5  на единицу
interferenceRange         = 2    позиции

конфликты:  synergy +8 · minor −10 · major −25 · lethal = блок

пороги:  80+ стабилен · 55–79 дрейф · 35–54 нестабилен
         15–34 критичен · 0–14 нежизнеспособен
```

**Проверка:** геном T2 (13 позиций) с 4 генами среднего размера, без конфликтов,
без шрамов → примерно `100 − 11×0.8 ≈ 91`. Один major-конфликт → 66 (дрейф).
Два → 41 (нестабилен). Это заставляет разносить гены, но не делает игру
невозможной. Похоже на правильный градиент.

## 4. Мутации и эволюция

```
baseMutationChance        = 0.002   за проверку (раз в 20 тиков)
errorProneMultiplier      = 3.0
highFidelityMultiplier    = 0.25
mutagenChamberMultiplier  = 5.0
fragileZoneMultiplier     = 3.0
immunePressureFactor      = 0.5

zoonoticJumpChance        = 0.02    от шанса сдвига рецептора
receptorShiftWeight       = 0.08    от всех мутаций
wildCapacityCap           = 14      дикий штамм не длиннее
maxStrainsPerOutbreak     = 6
```

**Проверка на вменяемость:** `0.002` за проверку = ~0.1 мутации на хоста за
игровой день. Для очага из 20 заражённых — 2 мутации в день. За неделю — 14
мутаций, из них сдвиг рецептора ~1, из них зооноз ~0.02. То есть **зоонозный
переход в естественном очаге среднего размера — примерно раз в 50 игровых
недель**. Редкое, драматичное событие. В пассажной камере с `error_prone` в
хрупкой зоне — в 45 раз чаще, то есть достижимо целенаправленно за дни.

**Это именно тот баланс, который нужен:** случайно почти не бывает, намеренно —
реально. Проверить тестом-симуляцией.

## 9. Профили сложности (датапаки)

**РЕШЕНИЕ ЗАКАЗЧИКА: дефолтный профиль — `normal` в жёстком виде, как описан
ниже.** Летальность, хронические последствия и порча мира включены. Смягчать
дефолт нельзя без согласования; для тех, кому нужно мягче, есть `casual`.

| Параметр | casual | normal | hardcore | sandbox |
|----------|--------|--------|----------|---------|
| Множитель дозы | 0.5 | 1.0 | 1.6 | 0 |
| Скорость распространения | 0.5 | 1.0 | 1.8 | 1.0 |
| Порча блоков | выкл | вкл | вкл | вкл |
| Шанс зооноза | 0.5× | 1.0× | 2.0× | 1.0× |
| Хронические состояния | выкл | вкл | вкл | выкл |
| Летальность для игрока | 0.3× | 1.0× | 1.5× | 0 |
| Аварии | мягкие | норма | жёсткие | выкл |
| Очки исследований | 1.5× | 1.0× | 0.8× | ∞ |
| Износ фильтров/баллонов | 0.5× | 1.0× | 1.5× | выкл |
| Обратимость порчи | быстрая | норма | медленная | мгновенная |

`sandbox` нужен не только игрокам, но и **разработчикам для тестов** — его стоит
сделать на этапе 0.

## 10. Ключевые конфиг-тумблеры (server)

```toml
[world]
worldCorruption = true            # порча блоков целиком
respectClaims = true              # уважать клейм-моды
spawnProtectionRadius = 0         # защищённый радиус от спавна
maxContaminatedChunks = 50000

[players]
playerInfection = true            # могут ли игроки болеть
# РЕШЕНИЕ ЗАКАЗЧИКА: хронические последствия переживают смерть.
# Снимаются только генной терапией T4. Не менять дефолт без согласования.
chronicConditionsSurviveDeath = true
pvpInfection = true               # заражение других игроков

[performance]
infectionCheckPeriod = 20
contaminationSpreadBudget = 64
corruptionBlockBudget = 16
debugPerfLogging = false

[progression]
# РЕШЕНИЕ ЗАКАЗЧИКА: общие на мир. Не менять дефолт без его согласия.
researchShared = true             # очки и разблокировки общие на мир
knowledgeShared = true            # открытые правила общие на мир

[safety]
maxHazardClass = 5                # ограничить максимальный класс на сервере
requireBslCompliance = false      # жёстко запретить работу выше BSL
```

## 11. Как балансировать (методика, а не числа)

1. **Балансные тесты-симуляции прежде всего.** Прогонять в CI:
   - Летальный штамм в замкнутой популяции **должен вымирать**
   - Умеренный штамм **должен закрепляться**
   - Отбор за 100 игровых дней не должен давать штамм длиннее `wildCapacityCap`
   - Эпидемия в деревне из 20 жителей без вмешательства **должна** приводить к
     коллапсу за 10–20 игровых дней (иначе последствий не чувствуется)
   - Вакцинация 70% деревни **должна** останавливать вспышку (порог коллективного
     иммунитета — проверка, что модель работает по-настоящему)

2. **Проверки на вменяемость вручную** — как в разделах выше. Каждое число должно
   иметь объяснение «почему столько», записанное рядом.

3. **Только потом живые прохождения.** И по ним править, но правки вносить в
   конфиг, а не в код.

Пункт про порог коллективного иммунитета — хорошая лакмусовая бумажка: если
вакцинация 70% населения не останавливает эпидемию, значит эпидемиологическая
модель реализована неправильно, а не «нужно подкрутить число».
