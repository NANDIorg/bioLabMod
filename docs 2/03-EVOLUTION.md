# 03 — Эволюция: мутации, отбор, направленное выведение

Это то, что делает мод живым, и то, чего нет ни в одном существующем моде.
Вирус — не предмет. Это процесс с собственной траекторией.

---

## 1. Мутация

Мутация происходит при **репликации** — то есть в живом хосте или в культуре.
Чем больше репликаций, тем больше шансов.

```
шансМутацииЗаПроверку =
      baseMutationChance                       // конфиг, ~0.002 за проверку
    × strain.mutationRate                      // из генов replication/*
    × (1 + viralLoad / maxLoad)                 // много вируса = много репликаций
    × (1 + immunePressure × 0.5)                // иммунный пресс ускоряет отбор
    × (2.0 − stability/100)                     // нестабильный геном мутирует чаще
    × hostMutagenFactor                         // радиация, мутагены, УФ
```

### Типы мутаций

| Тип | Вес | Что делает |
|-----|-----|------------|
| **Точечная** | 50% | Экспрессия случайного гена ±(5–20). Самая частая, мелкая |
| **Сдвиг рецептора** | 8% | Ген тропизма перескакивает на **соседний рецептор** по карте. ⚠️ Так возникает зооноз |
| **Потеря гена** | 15% | Случайный ген выпадает. Чаще при низкой стабильности |
| **Приобретение гена** | 10% | Берётся ген из «средового генофонда» (гены, присутствующие в этом чанке/хосте) или из генома хоста |
| **Дупликация** | 7% | Ген удваивается → экспрессия суммируется, но +size и −стабильность |
| **Регуляторная** | 7% | Меняется инкубация/порог дозы без смены генов |
| **Реассортация** | 3% | Только при `replication/segmented` и ко-инфекции: обмен сегментами |

### Что игрок может контролировать

| Инструмент | Эффект |
|------------|--------|
| `replication/error_prone` | ×3 к частоте мутаций — главный инструмент выведения |
| `replication/high_fidelity` | ×0.25 — для фиксации результата |
| Мутагенная камера (T3) | Облучение культуры: ×5 частота, −стабильность |
| Криохранение | Мутации полностью остановлены. Банк образцов |
| `locked` на гене | Этот ген не мутирует. Дорого по ёмкости, но позволяет «закрепить» нужное |
| Иммунный пресс | Заражение частично иммунного хоста ускоряет отбор по уклонению |

## 2. Естественный отбор: вирус в мире оптимизируется сам

Главная механика, дающая «вирус живёт сам».

Внутри одного очага заражения одновременно может существовать несколько штаммов
одной линии. Они **конкурируют**. Отбор работает по приспособленности:

```
fitness(штамм, окружение) =
      Σ_хосты (affinity[хост] × доступнаяПопуляция[хост])   // есть ли кого заражать
    × transmissionPower                                      // как хорошо передаётся
    × ожидаемаяДлительностьЗаразности                        // 1/летальность, грубо
    × (1 − среднийИммунитетПопуляции к его подписи)          // уклонение
    × envSurvivalFactor(биом, погода, свет)                   // устойчивость в среде
```

Каждый шаг симуляции очага: доля каждого штамма в популяции сдвигается
пропорционально его `fitness`. Мутанты с более высокой приспособленностью
вытесняют родителя.

### Что это значит для игрока — и это очень важно

1. **Твой безопасный штамм становится опасным сам.** Ты выпустил штамм с низкой
   летальностью и контактной передачей. Через три недели в мире доминирует его
   потомок с каплей вместо контакта — потому что капля передаётся лучше, и отбор
   её выбрал. Никакого скрипта «через 3 недели ухудшить» — это вышло из модели.
2. **Летальность отбирается вниз сама.** Слишком убийственный штамм убивает
   хостов, теряет носителей, проигрывает мягкому потомку. Реальная эволюционная
   закономерность, которую игрок обнаружит сам приборами.
3. **Иммунитет населения создаёт давление на уклонение.** Вакцинируешь деревню →
   отбор начинает благоприятствовать дрейфующим вариантам → **твоя вакцина
   сама создаёт себе противника**. Это глубоко, честно и очень по-настоящему.
4. **Попытки «просто подождать» наказываются.** Эпидемию надо тушить активно.

### Кап на эскалацию

Чтобы это не превратилось в неостановимую лавину, нужны тормоза (всё в конфиге):

- `maxStrainsPerOutbreak` (по умолчанию 6) — слабейшие линии вымываются
- Мутация **не может** добавить ген, которого нет в средовом генофонде, кроме
  сдвига рецептора. То есть аэрозоль не возникнет из ниоткуда, если в округе
  нет источника этого гена
- Ёмкость генома ограничена — дикий штамм не может стать длиннее, чем
  `wildCapacityCap` (конфиг, по умолчанию 14) без лабораторного синтеза
- `tropism/primate` через сдвиг рецептора возникает с множителем
  `zoonoticJumpChance` (по умолчанию **0.02** от базового шанса сдвига) — редкое,
  драматичное событие, а не рутина
- При зоонозном переходе игрок получает **явное предупреждение**: тревога от
  системы биомониторинга (если она построена), запись в Кодексе, звук. Это
  соответствует анти-цели «наказание без предупреждения»

## 3. Направленная эволюция: серийный пассаж

Главный **геймплейный** способ выведения на T2–T3, и он не требует дорогого
синтеза. Это реальная лабораторная техника (адаптация пассажем), и она
превращается в отличную инфраструктурную задачу.

### Как это работает

1. Игрок строит **Пассажную камеру** (многоблок) — изолированный отсек с
   подачей корма, воды и воздуха, вмещающий N животных одного вида
2. Заражает первую партию штаммом
3. Ждёт цикл (игровые дни). Внутри камеры штамм размножается и мутирует
4. **Собирает образец от самого больного/самого заразного хоста** — это и есть
   селекция
5. Заражает следующую партию собранным образцом
6. Повторяет 5–15 раз

Каждый пассаж сдвигает штамм в сторону **приспособленности к этому хосту**:
экспрессия тропизма растёт, появляются адаптации к условиям камеры.

### Что определяет направление

| Параметр камеры | Куда давит отбор |
|-----------------|------------------|
| Вид животного | Экспрессия тропизма к его рецептору + шанс сдвига к соседнему |
| Плотность посадки | Высокая → отбор на передачу; низкая → отбор на персистенцию |
| Вентиляция включена | Отбор на аэрозольную/капельную передачу |
| Вентиляция выключена | Отбор на контактную |
| Температура отсека | `env/thermostable` / `cryostable` |
| Освещение | `env/uv_resistant` |
| Частично вакцинированная партия | **Отбор на уклонение от иммунитета** |
| Низкие дозы при заражении | Отбор на высокую заразность |
| Мутаген/облучение | Больше мутаций, менее направленно |

Это даёт игроку **настоящую лабораторную работу**: он проектирует эксперимент,
а не нажимает кнопку. И это именно тот геймплей, который просили — «не верстак с
крафтом вирусов».

### Цена и риск

- Долго: один цикл = 1–3 игровых дня
- Расходно: животные гибнут, нужен поток живности → зачем-то нужна ферма
- **Опасно:** в пассажной камере эволюция идёт быстрее, чем где-либо. Именно
  здесь с наибольшей вероятностью возникнет зооноз. Камера требует BSL на класс
  **выше**, чем текущий класс штамма — именно потому, что штамм может измениться
- Результат не гарантирован: можно получить не то, что планировал. Нужен
  криобанк промежуточных образцов, чтобы откатиться

### Ослабление пассажем (attenuation)

Обратная техника, тоже реальная: пассируй «человеческий» штамм через **неродного**
хоста (например, птицу), и он потеряет приспособленность к примату. Результат —
живая ослабленная вакцина. Отличная механика: одна и та же установка работает и
на создание оружия, и на создание лекарства, разница только в выборе хоста.

## 4. Рекомбинация и химеры

### Ко-инфекция и реассортация

Если один хост заражён двумя штаммами одновременно и хотя бы один имеет
`replication/segmented`, возможен обмен сегментами. Потомок получает случайный
набор сегментов от обоих родителей.

Это:
- даёт **скачкообразные изменения** (антигенный шифт), а не плавный дрейф —
  резко ломает весь наработанный иммунитет населения;
- работает и в мире (аварийно), и в лаборатории (намеренно, в **Камере
  ко-инфекции**, T3);
- позволяет объединять достижения двух линий без дорогого синтеза.

**Свинья как смешивающий сосуд** (см. [02-INFECTION-MODEL.md](02-INFECTION-MODEL.md)) —
единственный хост, где могут встретиться птичья и приматная линии. Игрок, который
это откроет, получит мощный инструмент и очень большой риск.

### Химеры (T4)

Прямое лабораторное объединение: `structure/chimeric_shell` снимает
межцарственные конфликты и позволяет, например, вирус, заражающий и растения, и
млекопитающих. Это класс опасности V и требует BSL-4 с особым протоколом.

## 5. Как игрок это наблюдает

Эволюция бесполезна, если её не видно. Инструменты наблюдения — обязательная
часть системы, а не опция.

| Инструмент | Тир | Что показывает |
|------------|-----|----------------|
| Секвенатор | T2 | Геном образца, по одному гену за цикл |
| Сравнительный анализатор | T2 | **Дифф двух образцов**: что изменилось. Ключевой прибор |
| Станция биомониторинга | T3 | Сканирует округу: какие штаммы есть, их доли, тренд |
| Полевой детектор | T1 | Уровень загрязнения вокруг, примитивно |
| Кодекс: дерево линий | — | Полная родословная с отметками мутаций и дат |
| График доминирования | T3 | Доли штаммов в очаге во времени. Видно, как один вытесняет другой |
| Тревога зооноза | T3 | Громкое предупреждение при переходе на новый рецептор |

Дерево родословной в Кодексе — это **артефакт прохождения**. К концу игры там
будет история всего, что игрок сделал с миром. Это сильный эмоциональный крючок.

## 6. Что обязательно проверить тестами

- Мутация с фиксированным сидом полностью воспроизводима
- Распределение типов мутаций соответствует весам на большой выборке
- Сдвиг рецептора идёт только по карте соседства, никогда произвольно
- `tropism/primate` не возникает чаще, чем `zoonoticJumpChance`
- Приобретение гена невозможно, если гена нет в средовом генофонде
- Дикий штамм не превышает `wildCapacityCap`
- Отбор монотонен: штамм с заведомо большей `fitness` всегда наращивает долю
- Летальный штамм в замкнутой популяции вымирает (проверка естественного тредоффа)
- Число штаммов в очаге не превышает `maxStrainsPerOutbreak`
- Пассаж через неродного хоста снижает экспрессию исходного тропизма
- Реассортация невозможна без `replication/segmented`
- Криохранение полностью останавливает мутации
